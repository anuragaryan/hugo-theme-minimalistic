Minimalistic is a focused Hugo theme for personal sites, technical blogs, project pages, and lightweight resumes. The defaults stay intentionally quiet so your writing remains the main attraction.

## What the demo includes

This example site demonstrates:

- a configurable landing page
- a chronological blog list
- tagged posts and related content
- a data-driven projects page
- an optional data-driven resume
- configurable social links and custom assets

Use the navigation above to see each layout with representative content.

## Start with configuration

Set your identity and homepage copy in your site configuration:

```toml
[params]
  author = "Your Name"
  homeTitle = "Your Site"
  homeDescription = "A short introduction to your work and writing."
```

From there, add posts under `content/blog/` and customize only what your site needs.
